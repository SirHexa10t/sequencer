
`program` global variable (optional)
    only apply keybinds if specified program is currently in focus
    can alsp include wildcards (in case that the program launches with naming variation each time)
    not including this field means that the profile always applies


emergency_stop global variable (optional)
    specifies a key/chord (e.g.: F8) that when pressed: stops the applying of the profile.
        closes gracefully; for each bind that's in the middle of execution (especially `loop`s, but not only), release all pressed (yet unreleased) keys


`loop` variable for binds
    turns the bind into "toggle": run until key is pressed again, or until iterated the specified number of times
    since the script might be stopped mid-operation (and we don't want the entire sequence to carry on after pressing again to stop), all of the bind's (still) pressed keys are registered, and released upon user's stop

    loop = 1  # loop once. Same as not specifying loop at all
    loop = 4  # loop 4 times, then stop.
    loop      # loop indefinitely, only stopping when the user presses the bind again, or when program is terminated. Can we do that, withou `= <num>`? Maybe we have to specify `= inf`?




`RNG <chance>` bind run-command: introduce randomness; next commands would only run if randomized number scored lower than given chance
    `RNG 0.30`  # use RNG to give a chance of 0.30 for the next commands' activation 
        `RNG 30%`  # same. Another valid form 
        `RNG 3/10` # same. Another valid form 
    `GNR`  # unique command, same format like `if` and `fi` in BASH: until we reach this command, all commands are part of

`sequencer` commands:
    profile-check - check if the written profile has issues (legal toml, no missing vars, no typos: non-existing commands/keys)
        -f/--format flag: format the file nicely (indent after "RNG" command, space args from run-commands so that they'll start on the same column, move 'modifier' keys to the start of chords)
    profile-apply <file> - enforce profile. Runs until stopped.
